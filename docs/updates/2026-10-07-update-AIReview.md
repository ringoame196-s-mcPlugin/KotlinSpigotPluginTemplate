## 🤖 Gemini API による AI ひとくちレビュー仕様

Detekt や Lint などの静的解析を通過した Kotlin コード（`src/**/*.kt`）に対し、Gemini API が自動でコードレビューを実施して PR にコメントを投稿します。

### レビューのコンセプト
- **ポジティブフィードバック**: Paper API の適切な使用や、定数管理・タブ補完・設計の工夫など、コードの良い部分を具体的に評価します。
- **ひとくちアドバイス**: 構文エラーやスタイル違反の指摘は避け、より Idiomatic Kotlin らしい書き方や可読性・パフォーマンス向上のヒントを 1 点に絞ってアドバイスします。

### 使用モデルとフォールバック構成
API サーバーの混雑（503 エラー）やレート制限（429 エラー）による CI 失敗を防ぐため、以下の優先順位で自動切り替え（フォールバック）を行います。

| 順位 | モデル名 | 特長・採用理由 | RPD（1日あたりの上限） |
| :--- | :--- | :--- | :--- |
| **メイン** | `gemini-3.5-flash-lite` | 高速・高レスポンス。混雑しにくく CI に最適 | **500 回** |
| **予備 1** | `gemini-3.1-flash-lite` | Lite 系の予備枠。メインと同等の高上限 | **500 回** |
| **予備 2** | `gemini-2.5-flash` | 超高安定モデル。障害時の最終防衛線 | 20 回 |

### 処理の流れ
1. Git Diff より変更された `.kt` ファイルの差分（最大 8,000 文字）を取得。
2. `google-genai` 公式 SDK を用いてプロンプトを送信。
3. レビュー結果（`### 🤖 Gemini AI ひとくちレビュー`）が正常生成された場合のみ、`gh pr comment` で PR へ投稿。
